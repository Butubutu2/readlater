ReadLater

所有页面的静态预览，双击 HTML 文件即可在浏览器中打开

🔐 登录 / 注册页 auth.html

邮箱密码登录表单、切换注册

🏠 主页（有内容） home.html

录入模块 + 按标签分区的未读内容 + 3 天提醒色条（红/橙/琥珀）

📦 主页（空状态） home-empty.html

首次使用的引导空状态

📖 已读页 read.html

已读内容列表 + 加载更多按钮

🔍 搜索页 search.html

关键词 + 标签 + 平台 + 状态组合筛选

💬 分类确认弹窗 modal.html

粘贴链接后 AI 分类确认弹窗

💡 说明

这些是纯粹的静态 HTML 文件，用 Tailwind CDN 渲染样式。双击文件或用浏览器打开即可查看，不需要服务器、数据库或其他配置。

完整项目代码在 readlater/src/ 目录中。
